# Getting Started with VitePress Clear Blog

VitePress Clear Blog is a clean, customizable blog theme built on top of VitePress. It provides everything you need to start writing.

## Features

- **Markdown-based** — write posts in familiar Markdown format
- **Tags & Collections** — organize content with tags and collections
- **Timeline** — browse posts chronologically
- **D3 Force Graph** — visualize connections between posts
- **RSS Support** — generate RSS feeds automatically
- **Dark Mode** — built-in light/dark theme support

## Quick Start

```bash
pnpm create blog-template my-blog
cd my-blog
pnpm install
pnpm dev
```

Visit `http://localhost:4000` to see your blog in action.

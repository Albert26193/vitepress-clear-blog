# Understanding the D3 Force Graph

The D3 Force Graph component visualizes the relationships between your blog posts as an interactive network diagram.

## How It Works

Each node represents a blog post, and edges connect posts that share tags or collections. The force simulation creates a natural clustering effect, grouping related content together.

## Interaction

- **Drag** nodes to rearrange the layout
- **Click** a node to navigate to that post
- **Zoom** in and out with scroll
- **Hover** to see post details

## Configuration

The graph behavior can be tuned through the theme configuration, adjusting forces like charge strength, link distance, and collision radius.

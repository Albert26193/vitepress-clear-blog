# vitepress clear blog

Fork from https://github.com/airene/vitepress-blog-pure

## Environment Requirements

- Node.js: >= 22.0.0
- pnpm: >= 9.0.0

## Quick Start

```bash
# Install dependencies
pnpm install

# Development
pnpm dev

# Build packages
pnpm build:packages

# Build docs
pnpm build:docs

# Preview docs
pnpm preview:docs
```

# LLM 友好支持

> 🤖 为 AI 辅助开发提供最佳体验

本项目在设计时充分考虑了与大语言模型(LLM)的协作，提供多种机制来增强 AI 对项目的理解能力。

## 核心特性

### 📄 项目文档完善

- **清晰的目录结构** - 模块化设计，易于理解
- **详细的代码注释** - TypeScript 类型注解齐全
- **完整的 README** - 每个子包都有说明文档

### 🔧 开发者友好配置

- **TypeScript 类型系统** - 完整的类型定义
- **ESLint 代码规范** - 一致的代码风格
- **Monorepo 架构** - 清晰的包职责划分

### 🤝 AI 协作优化

- **llms.txt 支持** - 提供项目概述给 LLM
- **脚注增强** - 丰富的脚注功能支持
- **上下文友好** - 合理的文件大小和结构

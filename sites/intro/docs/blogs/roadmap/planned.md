# 📋 计划中

> 未来功能规划与社区需求

## 功能规划

### 🌐 国际化 (i18n)

**优先级**: 中

- 多语言文档支持
- 语言切换组件
- 内容翻译机制

### 💬 评论系统

**优先级**: 中

可选方案：
- Giscus (GitHub Discussions)
- Utterances (GitHub Issues)
- Waline (自部署)

### 📡 RSS 优化

**优先级**: 低

- 全文输出
- 分类订阅
- 自定义模板

### 🎨 主题定制

**优先级**: 中

- 主题配色方案
- 字体配置
- 布局选项

### 📊 数据统计

**优先级**: 低

- 文章字数统计
- 阅读时间估算
- 访问量统计（可选）

## 社区需求

> 来自用户的功能建议

| 需求 | 来源 | 状态 |
| ---- | ---- | ---- |
| 文章置顶 | Issue #xx | 考虑中 |
| 系列文章 | Issue #xx | 计划中 |
| 草稿模式 | Discussion | 考虑中 |

## 如何提交需求

1. 在 GitHub 创建 Issue
2. 使用 Feature Request 模板
3. 描述需求背景和期望效果

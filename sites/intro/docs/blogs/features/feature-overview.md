# 功能概览

> 📋 项目全部功能的完整清单

## 1. Markdown 基础语法

> VitePress 默认支持的标准 Markdown 语法

### 1.1 文本格式化

- [x] **粗体文本** - `**text**` 或 `__text__`
- [x] *斜体文本* - `*text*` 或 `_text_`
- [x] ~~删除线~~ - `~~text~~`
- [x] `行内代码` - `` `code` ``
- [x] [超链接](https://vitepress.dev) - `[text](url)`
- [x] 脚注支持[^1] - `[^1]`

### 1.2 标题层级

- [x] 一级标题 `# H1`
- [x] 二级标题 `## H2`
- [x] 三级标题 `### H3`
- [x] 四级标题 `#### H4`
- [x] 五级标题 `##### H5`
- [x] 六级标题 `###### H6`

### 1.3 列表

- [x] 无序列表 - `-` 或 `*` 或 `+`
- [x] 有序列表 - `1.` `2.` `3.`
- [x] 任务列表 - `- [ ]` 和 `- [x]`
- [x] 嵌套列表 - 支持多层嵌套

### 1.4 引用与分隔

- [x] 块引用 - `> quote`
- [x] 嵌套引用 - `>> nested`
- [x] 水平分隔线 - `---` 或 `***`

### 1.5 表格

- [x] 基础表格
- [x] 对齐方式（左/中/右）
- [x] 表格内 Markdown 语法

### 1.6 图片与媒体

- [x] 图片插入 - `![alt](url)`
- [x] 图片标题 - `![alt](url "title")`
- [x] 外链图片支持

# ✨ 功能特性

> 本章节介绍项目的主要功能特性

## 功能概览

项目提供丰富的博客功能，旨在打造类 Obsidian 的双链笔记体验：

```mermaid
mindmap
  root((功能特性))
    博客系统
      文章列表
      卡片视图
      标签分类
    图谱视图
      D3 力导向图
      双链关系
      交互探索
    Markdown 增强
      WikiLink
      Callout
      Mermaid
    搜索导航
      本地搜索
      时间线
      标签云
```

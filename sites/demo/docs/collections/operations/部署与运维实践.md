# 部署与运维最佳实践

从 Docker 容器化到生产环境监控，本文覆盖部署运维全流程。

## Docker 多阶段构建

```dockerfile
# 构建阶段
FROM node:22-alpine AS builder
WORKDIR /app
COPY package.json pnpm-lock.yaml ./
RUN corepack enable && pnpm install --frozen-lockfile
COPY . .
RUN pnpm build

# 运行阶段
FROM node:22-alpine
WORKDIR /app
COPY --from=builder /app/.vitepress/dist ./dist
EXPOSE 8080
CMD ["npx", "serve", "dist"]
```

多阶段构建将构建依赖和运行时依赖分离，最终镜像体积可减少 70% 以上。

## Kubernetes 基础部署

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: blog-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: blog
  template:
    spec:
      containers:
        - name: blog
          image: blog:latest
          ports:
            - containerPort: 8080
```

## 监控告警体系

- **Prometheus**：指标采集与时序存储
- **Grafana**：可视化仪表板与告警规则
- **AlertManager**：告警路由与通知（Slack/Email/PagerDuty）

关键监控指标：CPU/内存使用率、请求延迟 P50/P99、错误率 5xx、磁盘 I/O。

## 日志管理

ELK 技术栈（Elasticsearch + Logstash + Kibana）提供集中式日志收集与分析：

```bash
docker compose up -d elasticsearch logstash kibana filebeat
```

结构化日志（JSON 格式）更方便检索和聚合。

## 灾备与恢复

- 数据库定期自动备份（cron + pg_dump）
- 多区域部署与 DNS 故障转移
- 备份恢复演练（至少每季度一次）

# 脚注系统详解

VitePress Theme Link 的脚注系统基于 markdown-it-footnote，并提供 FooterRef 组件增强交互。

## 基础脚注语法

在正文中使用 `[^标识符]` 引用脚注[^1]，然后在文档任意位置定义脚注内容[^2]。

[^1]: 这是一个简单的脚注，只包含纯文本。

[^2]: 这是另一个脚注。

## 富文本脚注

脚注内可以包含 Markdown 格式：

[^3]: 脚注可以包含 **粗体**、*斜体*、`行内代码`，甚至列表：
    - 列表项 1
    - 列表项 2

## 多段落脚注

[^4]: 这是第一段。
    
    这是第二段。注意段落之间需要空行并保持缩进。

## 脚注回链

点击脚注的回链符号 ↩ 可以跳回引用位置。这在查阅长文档时非常方便[^3]。

## FooterRef 组件

Theme 内置的 FooterRef 组件在悬停时显示 tooltip 预览：

当鼠标悬停在脚注引用上[^4]，会弹出包含脚注内容的 tooltip，无需滚动到页面底部。

## 脚注编号

脚注按出现顺序自动编号[^5]，无需手动维护顺序。

[^5]: 编号由 markdown-it-footnote 自动处理，支持有序列表样式的数字编号。

## 使用建议

1. 脚注适合补充说明、引用来源、术语解释
2. 避免脚注内容过长（超过 200 字建议考虑正文说明或 Callout）
3. 脚注标识符建议使用语义化的英文（如 `[^note-about-x]`），方便维护

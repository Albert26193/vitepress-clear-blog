# Markdown 文本格式化全解

Markdown 的核心理念是**易读易写**。本文覆盖从标题到转义的全部基础格式化语法。

## 标题层级

# h1 — 最大标题
## h2 — 二级标题
### h3 — 三级标题
#### h4 — 四级标题
##### h5 — 五级标题
###### h6 — 六级标题

推荐每个文档只有一个 h1，其他层级按需使用。

## 文本强调

| 语法 | 效果 |
|------|------|
| `**粗体**` | **粗体文字** |
| `*斜体*` | *斜体文字* |
| `***粗斜体***` | ***粗斜体*** |
| `~~删除线~~` | ~~删除线文字~~ |
| `==高亮==` | ==高亮标记== |

可以混合使用：**这是 *嵌套斜体* 的粗体**。

## 引用块

> 一级引用块
> > 二级嵌套引用块
> > > 三级嵌套引用块

引用块可以包含其他元素：

> ### 引用中的标题
>
> - 列表项 1
> - 列表项 2
>
> ```js
> console.log('引用块中的代码')
> ```

## 水平分割线

---

或 `***`、`___`：

***

## 转义字符

使用反斜杠转义特殊字符：

\* 这不是斜体 \*
\` 这不是行内代码 \`
\[ 这不是链接 \]
